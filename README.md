# R4 Sewa Tenda Jadi

Website resmi R4 Sewa Tenda Jadi untuk memperkenalkan layanan penyewaan tenda dan meja bundar.

## Fitur Website

- Tampilan responsif untuk desktop dan mobile.
- Banner R4 Sewa Tenda Jadi.
- Pilihan tenda ukuran 6 × 8.
- Pilihan tenda ukuran 4 × 8.
- Tenda biasa tanpa plafon.
- Tenda spesial dengan plafon.
- Penyewaan meja bundar.
- Paket komplit: 1 kotak tenda + plafon + 4 meja bundar.
- Pemesanan langsung melalui WhatsApp admin.
- Animasi halaman menggunakan CSS dan JavaScript.

## Teknologi

- HTML5
- CSS3
- JavaScript

## Pengaturan WhatsApp Admin

Buka file `index.html`, cari kode:

```javascript
const ADMIN_WHATSAPP = "6281234567890";
```

Ganti nomor tersebut dengan nomor WhatsApp admin R4.

Gunakan format nomor 62 tanpa tanda + dan tanpa angka 0 di depan.

## Cara Hosting dengan GitHub Pages

1. Buat repository GitHub dengan nama `r4-sewa-tenda-jadi`.
2. Upload file `index.html` dan `README.md`.
3. Buka Settings.
4. Pilih Pages.
5. Pilih Deploy from a branch.
6. Pilih branch `main`.
7. Pilih folder `/(root)`.
8. Klik Save.

Website akan tersedia dengan alamat:

`https://USERNAME.github.io/r4-sewa-tenda-jadi/`

Ganti USERNAME dengan username GitHub Anda.

## Struktur Folder

```text

├── index.html

```
